# 🏡 Estatica.AI – Smart Real Estate Price Prediction Platform

An AI-powered real estate valuation platform that helps users estimate property prices using machine learning insights, dataset-driven analytics, and interactive visualizations.

Built with a modern React + Vite architecture, Estatica.AI combines predictive analytics, market intelligence, and explainable AI to provide transparent property valuation experiences.

---

## 🌐 Live Demo

**Application:** https://real-estate-ai-flax-nine.vercel.app/

---

## 📖 Overview

Estatica.AI is a data-driven property valuation platform designed to analyze residential property characteristics and generate intelligent price predictions.

The system leverages a curated dataset of 12,540+ property records and applies statistical analysis, feature importance evaluation, similarity matching, and AI-powered explanations to help users understand how different factors influence real estate prices.

## ⚙ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Jgopi07/real-estate-ai.git
```

### Navigate to Project

```bash
cd real-estate-ai
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

---

## 🚀 Deployment

This project is deployed using Vercel.

```bash
npm run build
```

Deploy the generated production build directly through Vercel.
